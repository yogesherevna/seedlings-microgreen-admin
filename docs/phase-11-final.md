# Phase 11 — Final Website CMS Implementation

This phase finalizes the Admin Website CMS against the uploaded Seedlings V2 prototype.

Rules implemented:
- CMS is website-specific, not a generic page builder.
- Website Pages are predefined and selected by the administrator; technical page identity is not editable.
- Homepage has fixed V2 sections only; no add/delete/reorder section controls.
- Hero Slider is repeatable.
- Journey has fixed V2 blocks and fixed process steps.
- Microgreens and Contact use page-specific fields.
- Products remain outside CMS; Featured Microgreens is driven by the product Featured flag.
- Navigation is fixed to the V2 items; routes/order are not editable.
- Website Settings controls website-wide identity/contact/app links.
- FAQ, Testimonials and Blogs remain repeatable website content.
